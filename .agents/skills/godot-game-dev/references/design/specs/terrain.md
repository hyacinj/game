# 地形系统

> **最后更新**: 2026-07-25

---

## 需求描述

### 地形生成
- 2D 侧视图，地面由规则矩形块组成
- 当前：288 块（48 列 × 6 行），每块 40×40 像素
- 未来：支持不规则地形（高度图生成）+ 不同材质（土/石/铁）

### 可破坏性
- 每块有 HP，被爆炸波及后扣血
- HP 降低 → 颜色变暗（视觉反馈）
- HP ≤ 0 → 地形块消除（从场景树移除）
- 上方失去支撑的地形块 → 下落（待实现）

### 碰撞
- 每块为 StaticBody2D + RectangleShape2D
- 炮弹、单位与地形正常碰撞
- 地形被消除后碰撞体同时移除
