> **最后更新**: 2026-07-25

## 需求描述

### 玩家
- 放置在地形上方，可被炮弹伤害
- 当前只有一个玩家角色
- 未来：多角色队伍（肉鸽招募）

### 敌人
- 放置在地形上方，AI 控制（待实现）
- 多种类型（近战/远程/飞行——待设计）
- 当前只有一个敌人

### 属性
- HP：生命值，≤0 死亡
- 伤害：基础攻击力
- 位置：Node2D，非物理体（碰撞用事件系统）

### 状态效果（待实现）
- 灼烧：每回合扣血，持续 N 回合
- 冰冻：移动/攻击减速
- 中毒、眩晕等（P2）
