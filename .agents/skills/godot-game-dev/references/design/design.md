# 游戏总策划

> **最后更新**: 2026-07-25 | Godot 4.4.x
>
> Agent 了解游戏的**唯一入口**。从这里出发，按需深入 `specs/` 查看各系统拆解。

---

## 一句话定义

**回合制抛物线炮兵对战 + 肉鸽卡牌构筑**

类似百战天虫/ShellShock 的 2D 物理投掷玩法，叠加 Slay the Spire 式的战后选牌成长。

---

## 核心循环

```
选关 → 战斗（瞄准→发射→爆炸→敌回）→ 战后选牌 → 下一关
```
